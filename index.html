El método

Tres ejes, un objetivo: que el idioma se entienda.

No es acumular reglas sueltas, sino ver el sistema. Un enfoque cognitivo y comunicativo, con la sintaxis como columna.

法

Sintaxis primero

La gramática se explica por su lógica —por qué el chino ordena así sus argumentos—, no como una lista que memorizar.

读

Lectura y recitación

Textos graduados que se leen y se recitan (背诵) para afianzar estructuras, léxico, pronunciación y fluidez.

评

Evaluación con sentido

Ejercicios y retroalimentación alineados a cada objetivo; el error es información, no falta.
